# ARAAK Contract Builder

منشئ عقود مقاولات تفاعلي لشركة اراك الوطنية، يدعم عقود أعمال العظم والتشطيبات، مع مستويات متعددة للصياغة القانونية والحماية التعاقدية.

## المزايا

- عقود أعمال العظم والتشطيبات.
- Standard / Deluxe للتشطيبات.
- مستويات: مختصر، متوازن، متقدم، احترافي.
- ملفات صياغة تعاقدية متعددة.
- وحدات مستقلة للإخلال بالالتزامات والإنهاء والاستكمال وأوامر التغيير والمطالبات والضمانات.
- معاينة A4 قابلة للتحرير والطباعة PDF.
- حفظ واستعادة الإعدادات محلياً.
- تنزيل العقد النهائي كملف HTML مستقل.

## التشغيل

المشروع Static HTML/CSS/JavaScript ولا يحتاج Backend أو Build Step. يكفي فتح `index.html` أو نشر المستودع مباشرة على Vercel أو GitHub Pages أو Render Static Site.
